## 1. 项目概述

### 1.1 项目背景

短漫剧、动态漫、AI 短剧市场需求快速增长，但传统制作链路长、成本高、角色一致性难保证。个人创作者不会画、不会剪、不会配音；MCN 和网文/IP 方需要批量生产与快速验证。AIGC 模型已具备文本、图像、视频、语音生成能力，但缺少面向漫剧生产的 Agent 化工作流。

### 1.2 项目目标

构建一个 **AIGC 漫剧生成 Agent 产品**，将小说、创意或剧本自动转化为可发布的竖屏漫剧视频。

核心目标：
- 单集 60–180 秒，9:16 竖屏，MP4 输出。
- 从创意到成片草稿 < 30 分钟。
- 角色一致性肉眼可接受，相似度 > 85%。
- 制作成本较传统方式降低 80%。
- 支持批量生成与团队协作。

### 1.3 项目范围

**包含：**
- 文本/小说导入与剧本生成
- 角色设定与一致性管理
- 分镜生成与编辑
- 关键帧生成与局部重绘
- 图生视频与轻动态
- TTS 配音、音效、BGM
- 时间线合成与导出
- 内容安全审核
- 发布包生成

**不包含：**
- 电影级 3D 动画
- 复杂物理特效
- 真人短剧拍摄
- 全自动无人审核发布

### 1.4 成功标准

| 维度   | 标准                               |
| ------ | ---------------------------------- |
| 激活   | 首个可播放视频 < 30 分钟           |
| 质量   | 导出成功率 > 95%，审核通过率 > 90% |
| 一致性 | 角色相似度 > 85%                   |
| 效率   | 1 分钟漫剧草稿 < 30 分钟           |
| 商业   | MVP 后 3 个月付费转化率 > 5%       |
| 成本   | 单分钟算力成本持续下降 30%         |

## 2. 产品定义

### 2.1 一句话定位

面向短漫剧创作者的 AI 制片厂，通过多智能体协作，把小说、梗概或剧本自动变成可发布的竖屏漫剧视频。

### 2.2 目标用户

| 用户         | 痛点                       | 场景               |
| ------------ | -------------------------- | ------------------ |
| 个人创作者   | 不会画、不会剪、不会配音   | 脑洞/小说转漫剧    |
| MCN/短剧团队 | 产能低、成本高、角色不稳定 | 批量账号矩阵       |
| 网文/IP 方   | 想快速验证 IP 视觉化       | 小说前 10 章转漫剧 |
| 品牌营销     | 想做轻量剧情广告           | 品牌定制漫剧       |
| 漫画工作室   | 静态漫画动态化成本高       | 漫画转动态漫剧     |

### 2.3 产品原则

- 可控优先于全自动：关键节点可编辑、可锁定、可回滚。
- 一致性优先于单帧精美：角色、画风、剧情连贯更重要。
- 分钟成本优先于炫技：先做能批量生产的轻动画漫剧。
- 人机协同：Agent 生成，用户确认，系统执行。

### 2.4 核心流程

创建项目 → 剧本生成 → 角色设定 → 分镜生成 → 关键帧 → 动态视频 → 配音音效 → 合成导出 → 审核发布。

## 4. 多 Agent 设计与 Prompt 库

### 4.1 总控 Agent：制片人

**职责：** 理解用户目标，拆解任务，调度子 Agent，维护项目状态，关键节点请求确认。

**原则：** 每步输出 JSON；角色 ID、风格 ID、项目 ID 贯穿全流程；未确认不得进入下一步。

**Prompt 模板：**

```text
你是漫剧制片人 Agent。你的目标是把用户输入的故事创意，转化为可发布的竖屏漫剧。
你必须按以下流程调度：
1. 编剧 Agent 生成分集大纲与剧本
2. 角色 Agent 生成角色卡与音色
3. 分镜 Agent 生成分镜表
4. 美术 Agent 生成关键帧
5. 视频 Agent 生成动态镜头
6. 音频 Agent 生成配音、音效、BGM
7. 剪辑 Agent 合成导出
8. 审核 Agent 检查风险
9. 运营 Agent 生成发布包

规则：
- 每一步输出 JSON，字段必须完整。
- 角色 ID、风格 ID、项目 ID 必须贯穿所有步骤。
- 关键节点必须暂停，等待用户确认或修改。
- 如果用户未确认，不得进入下一步。
```

### 4.2 子 Agent 职责

| Agent          | 职责                       | 输出                   |
| -------------- | -------------------------- | ---------------------- |
| 编剧 Agent     | 小说/梗概转漫剧剧本        | 大纲、剧本、分集表     |
| 角色导演 Agent | 角色设定、外貌、服装、音色 | 角色卡、三视图、表情库 |
| 分镜 Agent     | 拆镜头、景别、运镜、时长   | 分镜表                 |
| 美术 Agent     | 风格选择、场景概念、关键帧 | 关键帧、背景图         |
| 动态视频 Agent | 图生视频、运镜、表情、口型 | 镜头视频               |
| 音频 Agent     | TTS、音效、BGM、混音       | 音频轨                 |
| 剪辑合成 Agent | 时间线、字幕、转场、导出   | 成片                   |
| 审核 Agent     | 安全、版权、逻辑、连续性   | 风险报告               |
| 运营 Agent     | 标题、简介、标签、封面     | 发布包                 |

### 4.3 子 Agent Prompt 模板

#### 4.3.1 编剧 Agent

```text
你是短漫剧编剧。请把以下内容改编为竖屏漫剧。
要求：
- 每集 60–90 秒
- 前 3 秒必须有强钩子
- 每集结尾有反转或悬念
- 台词短、口语化、适合配音
- 输出 JSON：
{
  "episodes": [
    {
      "episode_no": 1,
      "title": "",
      "hook": "",
      "scenes": [
        {
          "scene_no": 1,
          "location": "",
          "time": "",
          "characters": [],
          "summary": "",
          "dialogue": [{"speaker": "", "line": "", "emotion": ""}],
          "narration": ""
        }
      ]
    }
  ]
}
```

#### 4.3.2 角色导演 Agent

```text
你是漫剧角色导演。请根据剧本生成角色设定。
要求：
- 每个角色必须有唯一 ID
- 外貌、服装、性格、声音要具体
- 输出可直接用于图像生成的英文 Prompt
- 输出 JSON：
{
  "characters": [
    {
      "id": "char_001",
      "name": "",
      "age": "",
      "gender": "",
      "appearance": "",
      "outfit": "",
      "personality": "",
      "voice": {"tone": "", "speed": "", "style": ""},
      "reference_prompt": "",
      "negative_prompt": ""
    }
  ]
}
```

#### 4.3.3 分镜 Agent

```text
你是漫剧分镜师。请把剧本拆成竖屏漫剧分镜。
要求：
- 每个镜头 2–5 秒
- 标注景别、运镜、画面描述、台词、音效、时长
- 画面描述必须包含角色 ID、场景、动作、表情、光线
- 输出 JSON：
{
  "shots": [
    {
      "shot_id": "ep1_s01",
      "episode": 1,
      "scene": 1,
      "duration": 3,
      "shot_size": "近景",
      "camera": "缓慢推近",
      "visual_desc": "",
      "characters": ["char_001"],
      "dialogue": "",
      "sfx": "",
      "bgm": "",
      "motion": ""
    }
  ]
}
```

#### 4.3.4 美术 Agent

```text
你是漫剧美术指导。请根据分镜生成关键帧。
要求：
- 保持角色 ID 一致
- 保持画风统一
- 竖屏 9:16
- 输出图像 Prompt：
Positive: {风格}, {角色参考}, {场景}, {动作}, {表情}, {光线}, {构图}, {镜头}
Negative: 畸形手, 多指, 崩脸, 低清晰度, 水印, 文字, 变形
```

#### 4.3.5 动态视频 Agent

```text
你是漫剧动态导演。请把关键帧转为轻动态视频。
要求：
- 保持角色一致
- 动作自然，幅度适中
- 支持推、拉、摇、移、轻微表情变化
- 输出：
{"shot_id": "", "motion_prompt": "", "duration": 3, "camera": "", "loop": false}
```

#### 4.3.6 音频 Agent

```text
你是漫剧音频导演。请根据台词生成配音与音效。
要求：
- 按角色音色分配 TTS
- 标注情绪、语速、停顿
- 输出 JSON：
{
  "voices": [{"shot_id": "", "character_id": "", "text": "", "emotion": "", "speed": 1.0}],
  "sfx": [{"shot_id": "", "type": "", "time": 0.5}],
  "bgm": [{"episode": 1, "mood": "", "start": 0, "end": 60}]
}
```

#### 4.3.7 剪辑合成 Agent

```text
你是漫剧剪辑师。请按时间线合成成片。
要求：
- 视频轨按 shot_id 排序
- 音频轨对齐台词
- 字幕自动断句
- 加转场、封面、片尾
- 导出 9:16 1080×1920 MP4
```

#### 4.3.8 审核 Agent

```text
你是内容安全审核 Agent。请检查以下内容：
- 政治、暴力、色情、违法、侵权
- 角色一致性、剧情逻辑、音画同步
- 输出 JSON：
{"risk_level": "low/medium/high", "issues": [], "suggestions": []}
```

#### 4.3.9 运营 Agent

```text
你是短漫剧运营。请生成发布包：
- 3 个标题，带钩子
- 简介 50 字内
- 10 个标签
- 封面文案 6 字内
- 输出 JSON
```

### 4.4 Agent 协作流程

```text
用户输入 → 制片人 Agent
  → 编剧 Agent → 用户确认
  → 角色 Agent → 用户确认
  → 分镜 Agent → 用户确认
  → 美术 Agent → 用户确认
  → 视频 Agent
  → 音频 Agent
  → 剪辑 Agent
  → 审核 Agent
  → 运营 Agent
  → 发布/导出
```

## 5. 技术架构与模型选型

### 5.1 总体架构

```text
用户端 Web/小程序
        ↓
API 网关 / 鉴权 / 计费
        ↓
项目服务：项目、剧集、角色、分镜、资产
        ↓
Agent 编排层：总控 + 九类子 Agent
        ↓
工作流引擎：DAG、重试、断点、并发、成本控制
        ↓
模型服务层：LLM / 图像 / 图生视频 / TTS / ASR / 唇形 / 超分
        ↓
资产库：对象存储、向量数据库、角色库、风格库、音色库
        ↓
渲染合成：FFmpeg、时间线、字幕、转场、导出
        ↓
发布中心：抖音 / 快手 / B站 / 导出包
```

### 5.2 模型选型

| 能力     | 选型方向                      |
| -------- | ----------------------------- |
| LLM      | GPT-4o / Claude / 通义 / 智谱 |
| 图像生成 | Flux / SDXL / 可图 / 即梦     |
| 图生视频 | 可灵 / Runway / Pika / 即梦   |
| TTS      | CosyVoice / GPT-SoVITS / 火山 |
| ASR      | Whisper / Paraformer          |
| 唇形同步 | Wav2Lip / SadTalker           |
| 超分     | Real-ESRGAN                   |
| 向量库   | Milvus / Qdrant               |
| 工作流   | Temporal / Prefect / Airflow  |
| 存储     | S3 / OSS / COS                |
| 数据库   | PostgreSQL / MySQL            |
| 消息队列 | Kafka / RabbitMQ              |
| 监控     | Prometheus + Grafana          |

### 5.3 一致性方案

- 角色 ID 贯穿全流程
- 角色参考图 + LoRA/Adapter
- 固定 seed + 面部 ID
- 服装状态机
- 多视角参考
- 人工锁定关键角色

### 5.4 成本控制

- 草稿低分辨率
- 批量生成
- 缓存复用
- 失败重试上限
- 项目预算控制
- 高峰期排队

### 6.3 页面原型描述

#### 6.3.1 项目工作台

三栏布局：
- 左栏：项目列表、剧集、分镜树
- 中栏：视频预览、时间线缩略
- 右栏：Agent 对话、参数、生成按钮

底部：生成进度、成本、导出按钮。

#### 6.3.2 剧本工作台

- 顶部：项目名、题材、集数
- 左侧：分集大纲
- 中间：剧本编辑器
- 右侧：Agent 改写、钩子优化、台词润色
- 底部：确认并锁定剧本

#### 6.3.3 角色工作台

- 角色卡片列表
- 角色详情：三视图、表情、服装、音色
- 参考图上传/生成
- 一致性锁定按钮
- 角色 ID 复制

#### 6.3.4 分镜工作台

- 表格视图：镜号、景别、运镜、时长、台词、音效
- 画布视图：关键帧缩略图
- 右侧：生成、局部重绘、换装、换背景

#### 6.3.6 发布中心

## 8. 风险与应对

| 风险         | 影响       | 应对                          |
| ------------ | ---------- | ----------------------------- |
| 角色一致性差 | 成片不可用 | 角色卡 + LoRA + 人工锁定      |
| 生成不可控   | 返工多     | 人机协同关卡、可回滚          |
| 版权风险     | 合规问题   | 输入声明、声音/音乐授权、审核 |
| 算力成本高   | 毛利低     | 草稿低分辨率、缓存、批量      |
| 同质化       | 用户流失   | 题材模板 + 风格资产 + 社区    |
| 平台审核     | 无法发布   | 生成标识、内容安全            |
| 进度延期     | 上线推迟   | MVP 范围收敛、优先核心链路    |

## 9. 验收标准

### 9.1 MVP 验收

- 能完成 3–5 角色、10–20 镜头、60 秒竖屏漫剧
- 角色一致性肉眼可接受
- 音画同步基本对齐
- 审核通过率 > 90%
- 导出成功率 > 95%
- 首个可播放视频 < 30 分钟

### 9.2 上线标准

- 核心流程无阻塞
- 任务可重试、可断点续跑
- 成本可监控
- 用户可导出 MP4 与发布包
- 内容安全审核生效

## 10. 运营与商业化

### 10.1 商业模式

- C 端：免费额度 + 会员 ¥39/月 + 算力点数包
- B 端：MCN/网文平台 ¥999–9999/月
- API：按生成分钟数计费
- 定制：品牌漫剧、IP 漫剧按项目收费
- 交易抽成：角色、场景、模板、音色资产市场

### 10.2 核心指标

- 北极星：每周可发布漫剧分钟数
- 激活：首个可播放视频 < 30 分钟
- 质量：导出率、重生成率、审核通过率
- 留存：周活跃创作者、周项目数
- 商业：付费转化率、单分钟成本、毛利
- 成本：单分钟算力成本、缓存命中率
